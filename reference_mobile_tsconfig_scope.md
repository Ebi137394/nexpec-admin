The root `tsconfig.json` (Expo app) had `include: ["**/*.ts","**/*.tsx"]` + `exclude: ["node_modules"]` only — so it ALSO type-checked `apps/web/**` (Next.js, has its own tsconfig + `npm run typecheck -w @nexpec/web` gate) and `supabase/functions/**` (Deno: `Deno` global, `https://` imports, `.ts` import extensions — all invalid under the RN config). That produced ~3400 false-positive errors; a heap-boosted run printed `Found 3537 errors in 533 files`.

Fix (commit 2fc3920 on chore/schema-squash): added `"apps/web"`, `"supabase"`, `.expo`, `dist`, `babel.config.js` to `exclude`. Now the root `tsc` reflects only the Expo app. CONFIRMED post-scoping count: **372 errors in 86 files** (all in `app/**`, `src/**`, `types/**` — zero Deno/Next noise), down from 3537. Biggest clusters: `src/screens/OperationsDashboard.tsx` (24), `app/(shared)/applicant/[id].tsx` (36), `src/screens/ProfileScreen.tsx` (17 — Lucide icon→ComponentType prop mismatch, a recurring pattern), `app/(inspector)/earnings.tsx` (18), VisualPipeline/operations types drift. `types/application.ts` fully fixed (union + STATUS_TRANSITIONS 'reviewing' key, commits 2fc3920+7fde963). **Binary is NOT gated by TS.** EAS `production` profile = Android `:app:bundleRelease` + iOS Release; no prebuild/postinstall tsc hook; Babel/Metro strip types at bundle time. `typecheck` (`npm run typecheck --workspaces`) is CI/hygiene only. So TestFlight/Play binaries compile regardless of tsc count. Keep CI mobile-typecheck gate OFF until the real (scoped) count is burned to 0. Related: [[reference_web_build_typecheck_gated]].

Sandbox caveat: full scoped `tsc` exceeds the 45s bash cap and background runs get reaped (per-call PID namespace + die-with-parent) — get the real count from a local heap run: `node --max-old-space-size=8192 node_modules/typescript/bin/tsc --noEmit`. **To verify a FEW changed files inside the sandbox (confirmed 2026-06-25):** write a throwaway `tsconfig.waveN.json` = `{ "extends": "./tsconfig.json", "include": [<changed .tsx files>] }`, run `npx tsc --noEmit -p tsconfig.waveN.json` (checks those files + their full transitive import closure, completes <45s), then delete it.
