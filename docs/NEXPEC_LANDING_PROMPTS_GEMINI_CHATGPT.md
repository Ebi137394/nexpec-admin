# NEXPEC Landing — Prompt Pack for Gemini (Nano Banana) & ChatGPT Image

Same art direction as the Midjourney master pack, rewritten for **Gemini /
"Banana2"** and **ChatGPT image**. Differences from the MJ version:
- No `--ar / --style / --stylize / --v / --no` flags — these models read plain
  language. Aspect ratio and "what to avoid" are written as sentences.
- Every data/readout/hash/UI element is now **abstract and explicitly
  non-legible**, because both models try to render real text and usually garble
  it. We keep the sci-fi feel without broken letters.
- Hex codes are kept *and* described in words (these models honor described color
  better than raw hex).

**Tool tips:** In ChatGPT, paste a prompt and, if needed, add "make it a square
image" or "a wide 16:9 landscape image." In Gemini, paste the prompt and state
the ratio in words; to keep the set consistent, generate one first, then upload
it and say "match this exact lighting, color grade and style" for the others
(its consistency strength — the equivalent of Midjourney's style reference).

## Notes for both tools
- **Consistency across the set:** generate #6 or #1 first, then (in Gemini especially) upload it as a reference and ask the model to "keep the exact same lighting, color grade, violet/navy palette and mood" for each of the others. ChatGPT: keep the same chat thread and say "same style and palette as the last image."
- **Color drift:** if the violet turns blue or magenta, add "the violet must be a vivid amethyst electric purple (RGB 124, 58, 237), not blue." If the navy washes out, add "the background should be almost black, a very deep navy."
- **Aspect ratio:** ChatGPT supports square (1024×1024) and landscape (1536×1024); ask explicitly. Gemini: state "square" or "wide 16:9 landscape" in the prompt.
- **If any garbled text appears anyway**, regenerate with "absolutely no text or symbols of any kind, only abstract glowing shapes" appended.
- **Export:** generate at the largest size each tool offers, then we'll place them into the `assets-manifest` slots (5 square tiles + 4 landscape tech backgrounds).
