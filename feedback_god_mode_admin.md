ebi's rule (2026-05-31): there is NO separate `super_admin` role in NEXPEC business logic — there is ONE `admin` role and it IS ebi. `admin` is absolute God-mode with 100% unrestricted access to every feature/setting/domain/read/write/override on BOTH the Next.js web dashboard and the Expo app. Where code separates them, unify so `admin` ⊇ `super_admin` (admin passes everywhere super_admin passes).

**Why:** ebi is the sole platform owner; any gate that checks `role = 'super_admin'` alone silently locks the owner out of their own platform — exactly the bug found in inspection-domains.tsx.

**How to apply:** every God-mode gate = `nx_is_admin()` semantics = `role IN ('admin','super_admin')` (SQL) / `role === 'admin' || role === 'super_admin'` (TS).
