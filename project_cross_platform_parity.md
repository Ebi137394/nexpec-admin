ebi's product principle: **100% cross-platform accessibility — a true 1:1 mirror of capability across web and mobile.** An inspector must be able to write/submit reports on the **web** from a laptop; a client/super-admin must manage the **entire** platform from the **mobile** app. The current UI leans (mobile = field roles + on-device capture; web = back-office/oversight), but that asymmetry is a **GAP TO CLOSE, not a design choice** — do NOT call it "intentional" again (I made that mistake in the §3 sync check; ebi corrected it).

Good news / enabler: the data + contract layer is **already platform-agnostic** — one Supabase Postgres, the same SECURITY DEFINER RPCs, the `@nexpec/shared-core` typed contract (imported by both surfaces — 55 web files), and 61 real-time subscriptions on both. So reaching full parity is a **UI-surface sweep, not a backend re-architecture**. Already-shared capability: inspectors submit reports on web (`inspector/submit-report`); clients/admins/super-admins have full mobile areas. Remaining deltas: agency / senior-inspector / organization areas are mobile-only on web; some finance/enterprise depth is web-only on mobile. Tracked as the lead v2 pillar in `docs/NEXPEC_1.0_AUDIT_AND_VISION.md` §5. Keep universal accessibility in mind for all future roadmap work. See [[reference-offline-sync-hardening]], [[user-profile-ebi-nexpec]].

**Parity-brick campaign — build ONE solid brick at a time, verify each (scoped tsc + `npm run qa:outbox` guardrail) before moving on.** Proven playbook: dispatch a mapping agent to capture the web source-of-truth exactly → build the mobile screen reusing the sibling design system (palette `C`: bg #020420, primary #7C3AED, card #0B1138; model new screens on `app/(client)/finance/invoices.tsx`) → RLS is the real gate (role check only hides UI) → idempotent handlers, online writes carry `// outbox-exempt:` pragma ON the `.from()` line directly above the write → wire reachability → verify. New user-facing labels routed through `t()` must be registered in `src/i18n/translations.ts` (interface + all 3 locales: en/it/tr) or tsc fails.

SHIPPED bricks (mobile gaining web parity, all verified clean): admin invoice actions (`finance/invoices/[id].tsx`), budget envelopes + approval policies (`finance/budget-envelopes.tsx`/`budget-policies.tsx` via `set_department_budget`/`set_approval_policy` RPCs), Inspection Domains console (`(admin)/inspection-domains.tsx`, super-admin is_launched/is_active toggles), **Client Reports/Deliverables (`(client)/finance/reports.tsx`** — read-only list of handed-off jobs where `admin_confirmed_at IS NOT NULL`, GOLDEN_RULE_6; reached via a "Deliverables" Quick Action in the finance hub).
