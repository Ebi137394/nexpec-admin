Public, unauthenticated, SEO-indexable landing feed mirroring marketplace activity WITHOUT PII/price/poaching exposure. **RFC: docs/rfc/0001-public-teaser-marketplace-mvp.md.** Two sides: demand (sanitized job teasers) + supply (pseudonymous talent spotlights). Extends [[project_public_anonymization]] (anti-poaching) + reuses [[reference_nexpec_schema_gotchas]].

**Core principle:** privacy BY CONSTRUCTION — anon reads only purpose-built projections whose column lists physically exclude PII; the view's WHERE is the security boundary (views run as owner → bypass RLS) + `security_barrier=true`. MVP = anon VIEWS; Phase 3 graduates to trigger-refreshed projection TABLE. Both feeds carry `source_kind` (polymorphic from day one). Delivery = Next.js 15 RSC + `revalidate=60` (existing public pages are client-rendered = SEO-invisible; teaser sets the right pattern).

**Locked product decisions (2026-06-24):** (1) consent = opt-in toggle AND admin `is_featured`; (2) enterprise/agency demand default-PRIVATE (opt-in `public_listable`); (3) "vetted" = verified baseline + admin Featured; (4) ~60s ISR. Then TWO supply-rule overrides: **NO completed-jobs/rating threshold** (max visible talent; 0 jobs/ratings → emit NULL so UI omits, never "0 jobs completed"); **drop `organization_id IS NULL`** — ALL inspectors show individually but affiliation NEVER emitted (all "vetted NEXPEC talent").

**Verified schema:** leak was `get_marketplace_inspectors` + `get_public_profile(s)` deriving display_name from full_name/first+last + returning avatar_url, all GRANTed anon (160000 called them "existing-but-unused"; no TS call sites). `nxHandle` FNV-1a in src/core/utils/handle.ts + apps/web/src/lib/identity/inspectorHandle.ts. `jobs` has client_id/agency_id XOR owner (`jobs_owner_xor`) + domain enum + specialty_slugs → demand multi-role nearly free. profiles has is_featured/verification_status/is_active/status/deleted_at/country_of_residence already.
