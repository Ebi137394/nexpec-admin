`app/profile/security.tsx` is ONE shared Security Settings screen (all roles; auth ops are user-level). Audit found 5 features; fixing in sets:

- **SET 1 DONE (16971d8, frontend-only):** Biometric toggle was cosmetic (local state, no persist, reset on reopen) — now wires to `src/services/BiometricAuth` (`enableBiometricLogin`/`disableBiometricLogin` persist the AsyncStorage flag that `app/(auth)/sign-in.tsx` `attemptBiometricLogin` reads; mount restores via `isBiometricLoginEnabled`). Change Password now REAUTHENTICATES: `signInWithPassword(current)` before `updateUser`; min 8 + reuse block + Current Password field.
- **SET 2 DONE (fed1526, PENDING deploy):** Safe account deletion. Migration **20260801164000**: `profiles` + `deleted_at`/`anonymized_at`; `request_account_deletion()` SECURITY DEFINER (search_path pinned) GUARDS active jobs (`jobs.status` in pending_approval/open/assigned/in_progress/disputed as client/contractor/agency) + unsettled `wallets` (available_balance/pending_amount/escrow_amount/pending_payouts) → then ANONYMIZES PII + `status='suspended'` + `deleted_at`, RETAINS all linked job/deal/contract/invoice/audit rows. Legacy `delete_user()` neutralized → safe alias (was hard delete of profiles+auth.users). Edge fn **`delete-account`**: runs anonymize as the user (forwarded JWT → auth.uid()) then `auth.admin.updateUserById(ban_duration ~100y)` — BANS login, deliberately does NOT delete auth.users (preserves FK anchor). Frontend `handleDeleteAccount` invokes it; guard rejections return 200 `{ok:false,error}`. **DEPLOY: `supabase db push` + `supabase functions deploy delete-account`.**
- **SET 3 DONE (a4b239d, frontend-only):** 2FA enforced app-wide at the AuthGate (NOT just sign-in) so it covers password/biometric/social/session-restore. `AuthContext` computes `mfaRequired` on every session change via `getAuthenticatorAssuranceLevel()` (currentLevel 'aal1' + nextLevel 'aal2') + exposes `recheckMfa()`. New `app/(auth)/mfa-challenge.tsx` (listFactors→challenge→6-digit→verify, refreshes challenge on failure, Sign Out escape). `AuthGate` (app/_layout.tsx): `if (isAuthenticated && mfaRequired)` pin to `/(auth)/mfa-challenge` + block all routing; `mfaRequired` added to effect deps so it releases on AAL2. Takes effect on next bundle (no deploy).
- **SET 4 DONE (bee7976, PENDING db push):** Real Active Sessions. Migration **20260801166000**: `list_my_sessions()` + `revoke_session(uuid)` SECURITY DEFINER RPCs scoped to auth.uid() that read/delete `auth.sessions` (PostgREST can't expose the auth schema). list returns id/created_at/updated_at/not_after/user_agent/ip/aal + is_current (matched via `auth.jwt()->>'session_id'`); dynamic SQL = version-safe. revoke deletes one own session (refuses current). Frontend renders real list (deviceLabel from UA, last-active, ip, Current badge) + per-device revoke + graceful fallback to "this device" if RPC unavailable. **DEPLOY: `supabase db push`.** EPIC COMPLETE (Sets 1-4).
