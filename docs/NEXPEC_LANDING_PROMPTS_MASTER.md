## Pro generation workflow

- **Lock the family.** Generate **#6 (Provable AI)** or **#1** first; pick the best frame, then add `--sref <that image URL> --sw 80` to the other eight so lighting, grade and material language stay consistent across the set.
- **Sharper realism (optional):** swap `--v 6.0 → --v 6.1` if you have it — noticeably crisper photoreal detail and better small-text/geometry coherence. Keep everything else identical.
- **Quality:** `--q 2` (already included) doubles detail/GPU time — worth it for hero assets. Drop to `--q 1` for fast exploration passes.
- **Color fidelity:** Midjourney approximates hex — if violet skews blue or magenta, reinforce with "amethyst electric violet, RGB 124 58 237" and "true electric purple, not blue." If navy washes out, add "near-black navy, almost black."
- **Negative-space discipline:** if a comp fills the reserved zone, append e.g. `negative space right third must stay empty and dark` and nudge `--stylize` down ~30 (lower stylize obeys composition more literally).
- **The two 3D shots (#7, #8):** if you want glossier render polish over photographic control, try dropping `--style raw`; keep raw for grittier realism.
- **Finish:** upscale the chosen render with Midjourney's upscaler, then export. Target ~2400px on the long edge for crisp retina display; the 1:1 tiles can be ~1600×1600.
- **Variations:** use strong/subtle vary to iterate composition without losing the look; reroll seeds rather than over-editing the prompt.
