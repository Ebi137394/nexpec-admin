# Assets Directory

Place your logo file here:

- `logo.png` - Main NEXPEC logo (recommended size: 512x512px or higher for best quality)

The logo will be used in:
- Splash screen
- Login/Sign-up screens
- Navigation headers
- App branding

## Image Requirements

- Format: PNG with transparency
- Recommended size: 512x512px minimum
- Aspect ratio: 1:1 (square)
- Background: Transparent or matching app theme (#1A1A2E)
