The Named-Disclosure VIP "unlock inspector identity" fee is now collected via a REAL Stripe card charge (web-only), replacing the Layer-E placeholder ledger-only collection. **Decisions (2026-06-23):** reveal scope = "identity via Named-Disclosure" → REUSE the existing sealed-rider + 36-month non-circumvention covenant (do NOT build a parallel cheap "unlock profile" that would bypass anti-poaching); card surface = WEB ONLY (intentionally bypasses native IAP per App Store 3.1.1 / Play Billing real-world-service posture; mobile routes users to web). No IAP code exists in the repo (only `@stripe/stripe-react-native`), so "bypass IAP" was purely architectural, not code removal.

**Money-before-benefit gating (the core change):** identity reveal moved from signature → confirmed payment. `sign_agreement` (disclosure_amendment branch) now records the e-signature + books the `vip_disclosure_fee` leg as `'pending'` ONLY (no tier upgrade, no `identity_revealed_at` at signature — that was the prior behavior). New `stripe_settle_named_disclosure(p_agreement_id, p_payment_intent_id, p_amount_cents, p_transaction_ref_id)` (SECURITY DEFINER, **service_role-only**, idempotent on PI id) flips the leg → `'held'`, sets `deals.transparency_tier='named'`, stamps `inspector_engagement_meta.identity_revealed_at`. Matches rider §1 verbatim ("on execution of this Amendment AND collection of the Premium Fee"). Contract-before-money preserved: sign first; edge fn refuses to mint a PI unless `agreements.status='executed'`.
