# Screenshot spec — Apple

Captured on real simulators from the final release HEAD (no mockups, no
fabricated content; demo data only).

| Set | Device | Native px | ASC slot |
|---|---|---|---|
| iPhone 6.9" | iPhone 16 Pro Max sim | 1320×2868 portrait | iPhone 6.9" display (required; covers smaller iPhones) |
| iPad 13" | iPad Pro 13" (M4) sim | 2064×2752 portrait | iPad 13" display (required for iPad support) |

Up to 10 per set. Order tells the product story:
1. Marketplace / job discovery (inspector view)
2. Job posting or job details (client view)
3. Application & staged identity disclosure
4. Contract workflow
5. Inspection report (structured findings + photos)
6. AI Co-Inspector (with Beta/advisory banner visible)
7. Controlled chat (report control visible)
8. Manual payment — "Available now" + card "Coming soon"

`raw/` = untouched simulator captures. `framed/` = same captures over brand
background with one-line captions (exact same pixel sizes).

# Play deltas
- Phone: 2–8 shots, 16:9→9:16 range, ≤3840px — the 1320×2868 set is compliant.
- 7" tablet + 10" tablet slots: exported from the iPad 13" set (2064×2752
  fits both; Play accepts any in-range PNG).
- Feature graphic (1024×500) + 512 icon already in Feature-Graphic-and-Icon/.
